A thoughtful companion

Noor helps you explore Islamic texts through source retrieval. It is an AI assistant, not a qualified scholar. Interpretations and legal opinions can differ.

The local library contains all 6,236 Quran verses with English and Hindi translations, and five original Hadith summaries from Sunni collections. Published translations and translator footnotes are displayed verbatim with their references.

An optional local Ollama model can add explanations. Its output is labeled separately and may need review. Without a model, Noor displays retrieved passages directly.

Conversations stay in this page's memory and are cleared when you reload. The application does not save chat history. Optional source lookups request fixed JSON datasets; an optional model receives your question and retrieved passages locally.
